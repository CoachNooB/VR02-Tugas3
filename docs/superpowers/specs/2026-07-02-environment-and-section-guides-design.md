# Environment Textures and Section Guides

## Scope

Extend the deterministic Tugas 7 scene builder with textured environment surfaces,
four section-specific guide NPCs, a click-triggered head-hit reaction, and an
idempotent finish beacon. Existing gameplay transforms, controls, checkpoint order,
damage behavior, and the start guide remain unchanged.

## Environment Materials

Reuse the imported CC0 PBR maps and generated URP Lit materials. Assign materials by
semantic category:

- Platforms and checkpoint foundations use reinforced concrete.
- Structural walls use reinforced concrete with a darker wall tint.
- Gates use weathered metal while retaining their gameplay state and movement.
- Sweepers and damage obstacles use textured weathered metal while retaining a
  clearly red danger tint and emission.
- Start, gate, and finish stations use textured industrial metal while retaining
  cyan or gold interaction colors.

Material variants are shared assets generated by `T7_UpgradeAssetBuilder`; renderers
must not instantiate per-object materials. Gameplay colors remain readable after
texturing.

## Section Guide NPCs

Keep the existing start guide with its four-line tutorial. Instantiate the same guide
prefab once in each gameplay section, outside movement paths and interactable
raycasts. Configure each instance with one replayable line:

1. `Time your jumps between platforms and avoid the rotating machinery.`
2. `Push the yellow crate onto the pressure plate to open the gate.`
3. `Ride the moving platforms and keep clear of the sweeper.`
4. `Combine precise jumps and timing to reach the finish.`

All guides retain the three-meter E interaction range, world-space UI, automatic
line expiry, horizontal player-facing behavior, and Waving/Talking states.
`T7_TutorialNPC` accepts per-instance lines while preserving the default tutorial
lines for the start guide.

## Head-Hit Interaction

Import `Assets/Animations/Ch44_nonPBR@Head Hit.fbx` as a Humanoid, non-looping,
in-place clip using the Waving avatar. Add an animator trigger named `HeadHit` and a
one-shot `Head Hit` state. The reaction returns to Talking when `IsTalking` is true
and otherwise returns to Waving.

A player-side ray interactor handles left-click independently from E dialogue. It
triggers only when:

- the target is within three meters;
- the camera ray directly hits an NPC hit target; and
- the NPC is active.

This does not consume or alter the existing crate-push behavior; crate pushing still
only acts on the designated crate.

## Finish Beacon

The first valid finish interaction records completion and elapsed time. Later
interactions return the same completion message and recorded time without firing
completion behavior again, changing course state, or reporting that the finish is
locked.

## Determinism and Tests

Scene rebuilds remove and recreate the Tugas 7 root, so guide and dressing instances
cannot duplicate. Add automated coverage for:

- category-specific shared material assignments;
- default and per-instance NPC dialogue;
- all section guide instances using world-space UI;
- head-hit range and direct-hit requirements;
- animator parameters and non-looping head-hit clip;
- repeated finish interactions preserving the completion result.

Run scene rebuild, compilation, Edit Mode tests, and Play Mode tests before handoff.
Manual acceptance verifies texture readability, NPC placement, and animation
transitions in the Game view.
